# CRM ЗЦРБ — управление персоналом, планами и задачами

Внутренняя CRM ГАУЗ «Зеленодольская ЦРБ» для управления сотрудниками, подразделениями, планами, задачами и контролем исполнения.

## Стек

- PHP 8.0+
- Laravel 9
- MySQL / MariaDB
- Bootstrap 5
- jQuery + AJAX
- Blade

## Основные модули

1. **Оргструктура** — отделения, службы, кабинеты и административные подразделения, древовидная структура.
2. **Сотрудники** — ФИО, должность, подразделение, руководитель, контакты, статус, дата приёма.
3. **Роли и доступ** — администратор, руководитель, сотрудник.
4. **Планы** — личные планы сотрудников и планы, назначенные руководителем; дневные, недельные, месячные и произвольные периоды.
5. **Задачи** — постановка задач, приоритет, сроки, исполнитель, постановщик, наблюдатели, процент выполнения, статусы.
6. **Отчётность** — сотрудник описывает результат работы, прикладывает комментарий и фиксирует выполнение.
7. **Контроль** — просроченные задачи, задачи без отчёта, задачи на проверке, загрузка подразделений.
8. **Дашборд** — мои задачи, планы, просрочка, статистика выполнения и контроль подчинённых.
9. **Журнал действий** — история изменений ключевых сущностей.

## Базовые статусы задач

- `new` — новая
- `in_progress` — в работе
- `review` — на проверке
- `completed` — выполнена
- `cancelled` — отменена

## Принцип интерфейса

Основные операции выполняются без перезагрузки страницы через AJAX: создание/редактирование задач и планов, изменение статуса, процента выполнения, комментарии, фильтры и таблицы.

## Первый запуск

```bash
composer install
cp .env.example .env
php artisan key:generate
# настроить подключение к БД в .env
php artisan migrate --seed
php artisan serve
```

## Начальная учётная запись

После выполнения seed будет создан администратор:

- Email: `admin@zcrb.local`
- Пароль: `ChangeMe123!`

Пароль необходимо изменить после первого входа.

## План разработки

Первый этап: каркас Laravel, авторизация, оргструктура, сотрудники, планы, задачи, AJAX API и дашборд.

Далее: вложения, комментарии, уведомления, календарь, расширенная аналитика, экспорт Excel/PDF, KPI и журнал контроля.
