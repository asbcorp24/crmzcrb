# Аттестация ЗЦРБ — отдельный портал

Самостоятельное приложение **Laravel 9 + Bootstrap 5 + SQLite**. Оно находится в отдельной папке и не использует таблицы основной CRM.

## Что реализовано

### Супер-администратор
- создание и редактирование цехов;
- создание сотрудников: ФИО, цех, должность, логин, пароль;
- массовое создание сотрудников;
- автоматическая генерация логинов/паролей;
- просмотр ранее выданного пароля;
- сброс пароля;
- выгрузка CSV: **цех / ФИО / должность / логин / пароль**;
- включение/отключение сотрудников.

Пароль для входа хранится стандартным безопасным хешем Laravel. Дополнительно тот же пароль хранится в БД в **обратимо зашифрованном** поле `password_encrypted` с ключом `APP_KEY`, поэтому супер-админ может повторно посмотреть и выдать пароль. Открытый пароль в SQLite не хранится. **После начала работы не меняйте `APP_KEY`**, иначе ранее выданные пароли в `password_encrypted` нельзя будет расшифровать.

### Конструктор тестов и анкет
- тест или анкета;
- черновик / активен / закрыт;
- назначение одному или нескольким цехам;
- даты открытия и закрытия;
- ограничение времени;
- число попыток;
- проходной процент;
- анонимная анкета;
- разделы вопросов;
- обязательность;
- вес вопроса;
- редактирование и удаление вопросов.

Типы вопросов:
- один вариант;
- несколько вариантов;
- шкала;
- свободный текст;
- дополнительное поле «укажите коллег».

Для вариантов используется формат:

    A|Первый вариант
    B|Второй вариант
    C|Третий вариант

Правильные значения для теста:

    A,C

### Прохождение
Сотрудник входит под выданным логином и паролем. Он видит только активные тесты/анкеты, назначенные его цеху. Учитываются сроки, лимит попыток и таймер.

### Аттестация из CRM
Перенесена логика существующего модуля CRM:
- кампании аттестации;
- назначение цехов;
- взаимная оценка коллег своего цеха по шкале **1–4**;
- аттестационная комиссия;
- отдельная оценка комиссии по шкале **1–4**;
- комментарий комиссии;
- матрица результатов;
- средняя оценка коллег;
- средняя оценка комиссии;
- итоговая средняя;
- распределение оценок 1–4.

### Аналитика
- количество прохождений по тестам;
- средний процент;
- число сдавших;
- охват по цехам: ожидается / прошло / процент;
- средний результат по цеху;
- распределение ответов по вариантам;
- среднее значение шкал;
- текстовые ответы;
- рейтинг упоминаний коллег;
- результаты сотрудников;
- отдельная аналитика аттестации;
- графики на Chart.js.

## Быстрый запуск Windows

Откройте папку:

    attestation-portal

и запустите:

    install.bat

После установки:

    start.bat

Встроенный сервер будет доступен на:

    http://127.0.0.1:8085

## OpenServer

Для отдельного домена укажите DocumentRoot:

    .../crmzcrb/attestation-portal/public

Не указывайте корень `attestation-portal` — веб-сервер должен смотреть именно в `public`.

## Linux / хостинг

    cd attestation-portal
    chmod +x install.sh
    ./install.sh

Для nginx/apache DocumentRoot также должен указывать на:

    /path/to/attestation-portal/public

## Супер-админ

До первого запуска измените в `.env`:

    SUPERADMIN_FIO="Супер администратор"
    SUPERADMIN_LOGIN=superadmin
    SUPERADMIN_PASSWORD=ChangeMe123!

После:

    php artisan db:seed --force

Сидер создаст или обновит супер-админа.

## SQLite

База:

    database/database.sqlite

Миграции:

    php artisan migrate

Полный сброс тестовой базы:

    php artisan migrate:fresh --seed

## Основные URL

- `/login` — вход;
- `/` — задания сотрудника / панель супер-админа;
- `/attestation` — прохождение аттестации;
- `/admin/workshops` — цеха;
- `/admin/users` — сотрудники и пароли;
- `/admin/tests` — конструктор;
- `/admin/attestation` — кампании;
- `/admin/analytics` — аналитика тестов и анкет;
- `/admin/analytics/attestation` — аналитика аттестации.
